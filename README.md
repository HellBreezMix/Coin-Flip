# CoinFlip

Казино «Орёл или Решка» для OpenComputers.

## Установка

```
wget -f https://raw.githubusercontent.com/HellBreezMix/Coin-Flip/main/install.lua
lua /home/install.lua
lua /CoinFlip/main.lua
```

## Что нужно

- Компьютер с интернет-картой (для установки)
- Видеокарта и монитор 3 уровня
- Транспозер — приём предметов (пополнение)
- ME Interface — выдача предметов (вывод)

Стороны блоков задаются в `config.lua` → `config.hardware`.

## Как играть

Авторизация → выбираешь сторону → ставка → ИГРАТЬ.

Пополнение: кидаешь предметы в левый сундук, жмёшь ПОПОЛНИТЬ.
Вывод: жмёшь ВЫВОД, выбираешь сумму, забираешь предметы из правого сундука.

Выигрыш падает на баланс, обналичиваешь когда захочешь.

## Админка

Кнопка появляется у тех, кто прописан в `config.admins`.

## Данные

Лежат в `/CoinFlip/data/` — балансы, настройки, история, логи. При обновлении не трогаются.
